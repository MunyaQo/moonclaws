# Moonclaws (Minecraft 1.16.5, Forge)

Мод «Коты-воители»-стиля. Лунный камень (кварц + сырая треска + лазурит) превращает игрока в кота.

Как собрать мод на своём компьютере: дважды нажать «Собрать мод.bat» (нужна Java 8 JDK).
Готовый .jar сам попадёт в сборку CurseForge «Moonclaws». Журнал сборки — в папке logs.
Запасной способ: загрузить файлы в репозиторий на GitHub — вкладка Actions соберёт .jar.
Для игры нужен Minecraft Java 1.16.5 и Forge 1.16.5 (36.2.39 или новее).
